An original chess engine in 4,096 bytes of Python: alpha-beta search with quiescence, a transposition table, MVV-LVA + killer + history move ordering, and piece-square evaluation. It plays the make.fun tiny-chess-01 gauntlet to a fixed node budget per move — no clock, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=$MAKEFUN_ENV_URL python3 main.py
```
